# AI Powered Server

This server provides AI capabilities, including:
- Text-to-Speech (Parler, Piper)
- Conversation Logic (Maya OS)

## Requirements
Here are the detailed requirements and their purpose:
1. **parler-tts**: Main engine for high-quality text-to-speech generation.
2. **piper-tts**: Alternative fast text-to-speech particularly suited for on-device use.
3. **neon-memory**: Handles context and memory for the AI.
